# 学生信息管理系统（MySQL 版）

## 一、项目简介
本项目是一款基于 MySQL 数据库的学生信息管理系统，主要实现学生基础信息、课程、选课及成绩的一体化管理，适用于高校 / 培训机构的学生信息、课程成绩管理场景。

系统采用模块化的数据库设计，支持学生信息增删改查、课程管理、选课操作、成绩录入与统计等核心功能，适配 Navicat 等主流数据库管理工具，开箱即用。

## 二、技术栈
- **数据库**：MySQL 8.0+/9.0+（兼容 InnoDB 存储引擎）
- **字符编码**：utf8mb4（支持全量中文及特殊字符）
- **数据库工具**：Navicat Premium/Navicat for MySQL（推荐，适配数据导入、管理、可视化操作）

## 三、数据库设计
### 数据库基本信息
- 数据库名：`stu`
- 字符集：`utf8mb4`
- 排序规则：`utf8mb4_0900_ai_ci`
- 外键约束：开启（保证关联表数据一致性）

### 1. 学生表
存储学生核心基础信息，作为学生维度的主表。

| 字段名 | 类型 | 约束 / 说明 |
| --- | --- | --- |
| 学生ID | int | 自增主键，学生唯一标识 |
| 姓名 | varchar(20) | 非空，学生姓名 |
| 性别 | char(1) | 可选，值为“男/女” |
| 学号 | varchar(20) | 非空、唯一，学生学号 |
| 班级 | varchar(30) | 可选，学生所属班级 |
| 联系方式 | varchar(20) | 可选，学生联系电话等 |

### 2. 课程表
存储课程基础信息，作为课程维度的主表。

| 字段名 | 类型 | 约束 / 说明 |
| --- | --- | --- |
| 课程ID | int | 自增主键，课程唯一标识 |
| 课程名称 | varchar(50) | 非空，课程名称 |
| 学分 | int | 可选，课程对应学分 |
| 授课教师 | varchar(20) | 可选，授课教师姓名 |
| 上课时间 | varchar(50) | 可选，如“周一 1-2 节” |
| 地点 | varchar(50) | 可选，如“教学楼 302 室” |

### 3. 选课表
关联学生与课程的中间表，记录选课关系。

| 字段名 | 类型 | 约束 / 说明 |
| --- | --- | --- |
| 选课ID | int | 自增主键，选课记录唯一标识 |
| 学生ID | int | 非空，外键关联学生表.学生ID |
| 课程ID | int | 非空，外键关联课程表.课程ID |
| 选课时间 | varchar(255) | 可选，选课操作时间 |
| 状态 | varchar(10) | 可选，如“已选/退选/审核中” |

### 4. 成绩表
记录学生课程成绩，关联选课记录。

| 字段名 | 类型 | 约束 / 说明 |
| --- | --- | --- |
| 成绩ID | int | 自增主键，成绩记录唯一标识 |
| 选课ID | int | 非空，外键关联选课表.选课ID |
| 平时成绩 | decimal(4,1) | 可选，百分制（如 90.0） |
| 期末成绩 | decimal(4,1) | 可选，百分制（如 80.0） |
| 总评成绩 | decimal(4,1) | 可选，综合平时/期末的最终成绩 |

## 四、表间关系
- 学生表 **1:N** 选课表：一个学生可选多门课程
- 课程表 **1:N** 选课表：一门课程可被多个学生选择
- 选课表 **1:N** 成绩表：一条选课记录对应一条成绩记录

## 五、快速开始（适配 Navicat 操作）
### 环境要求
- 安装 MySQL 8.0 及以上版本（服务正常运行，默认端口 3306）
- 安装 Navicat Premium/Navicat for MySQL（任意支持 MySQL 的版本均可）

### 数据库部署（Navicat 可视化操作）
#### 方式 1：直接运行 SQL 脚本
1. 打开 Navicat，连接本地 MySQL 服务器（填写主机、端口、用户名、密码）；
2. 右键点击左侧「连接名」→「新建数据库」，命名为 `stu`，字符集选择 `utf8mb4`，排序规则选择 `utf8mb4_0900_ai_ci`，点击「确定」；
3. 选中新建的 `stu` 数据库，点击顶部「查询」→「新建查询」；
4. 将项目中 `stu(包含建表语句和测试数据).sql` 文件的全部内容复制到查询编辑器；
5. 点击「运行」按钮（▶️），执行完成后刷新数据库，即可看到所有表和测试数据。

#### 方式 2：导入 SQL 文件
1. 打开 Navicat，连接本地 MySQL 服务器，新建 `stu` 数据库（同方式 1 步骤 2）；
2. 选中 `stu` 数据库，右键→「运行 SQL 文件」；
3. 在弹出的窗口中点击「浏览」，选择项目中的 `stu(包含建表语句和测试数据).sql` 文件；
4. 点击「开始」，等待导入完成，刷新数据库即可。

### 验证部署（Navicat 操作）
1. 选中 `stu` 数据库下的「学生表」，点击「查看数据」，可看到 6 条学生测试数据；
2. 新建查询，执行以下 SQL 验证关联数据：

```sql
-- 关联查询学生选课及成绩
SELECT 
    s.姓名, 
    c.课程名称, 
    sc.选课时间, 
    g.平时成绩, 
    g.期末成绩, 
    g.总评成绩
FROM 学生表 s
LEFT JOIN 选课表 sc ON s.学生ID = sc.学生ID
LEFT JOIN 课程表 c ON sc.课程ID = c.课程ID
LEFT JOIN 成绩表 g ON sc.选课ID = g.选课ID;
